# Episódio 6 — Pós-lançamento

O sistema exporta seis CSVs (pedidos, itens, exceções, eventos de auditoria, clientes e produtos) pela rota `GET /api/export/<nome>.csv`. A página documenta colunas, relacionamentos sugeridos e as medidas que o dado permite calcular.

Não existe relatório de Power BI neste repositório, e os arquivos não foram abertos no Power BI. Só o endpoint foi testado: o teste E2E confere cabeçalho e linhas.
